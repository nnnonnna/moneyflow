# moneyflow

A privacy-first personal finance tracker that helps users manage income, expenses, and debts while gaining clear insights into their real financial state.

## Spec and build prompts

- **[MVP technical specification](docs/personal-finance-mvp-spec.md)** — stack, architecture, domain models, data layer, hooks, routing, UI theme (green + white), and feature requirements.
- **[Step-by-step implementation prompts](prompts/00-readme.md)** — run `01` through `10` in order to build the app without skipping steps.

## Run locally

```bash
npm install
npm run dev
```

```bash
npm run build   # vite build then tsc
npm run lint
```
